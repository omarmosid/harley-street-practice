# Scrape helper notes

This is internal — explains the scrape approach used in Phase 0.

## Source enumeration

1. `/sitemap.xml` — provides 68 URLs (pages, country visa pages, store products, etc.)
2. `/insights` page crawl — provides 11 article URLs (insights aren't in the sitemap)

Total: ~79 URLs.

## Extraction strategy (per page)

For each URL we use CDP MCP:

1. `navigate_page(url)`
2. Wait for content to render (Squarespace is JS-heavy)
3. Run an `evaluate_script` to extract:
   - `title` — `document.title`
   - `metaDescription` — `<meta name="description">`
   - `h1` — first `h1` text
   - `mainHtml` — `#page` or `main` outerHTML
   - `images` — array of `{src, alt, width, height}` from main content
   - `bodyText` — clean text for fallback
4. Convert HTML → Markdown using a small in-page DOM walker (turndown-style).
5. Save:
   - `content-cache/pages/<slug>.md` with frontmatter (title, description, original_url, scraped_at, images)
   - Image URLs queued for download

## Image download

Squarespace serves images via `images.squarespace-cdn.com/content/v1/.../filename.jpg?format=…`.
We:
- Strip the `?format=…` for the highest available rendition (Squarespace returns native size when no format specified, or `?format=2500w` for max).
- Download via `curl` to `content-cache/images/<hash>-<filename>`.
- Track in `images/manifest.json`: `{ originalUrl, localPath, alt, sourcePage }`.

## URL → slug mapping

Squarespace uses kebab-case slugs which we keep, with a few cleanups for new IA:

- `/` → `home.md`
- `/contact-us-1` → `contact.md`
- `/services-1` → `services-index.md`
- `/onlinebloodtest` → `online-blood-test.md`
- `/health-checks-1` → `occupational-health.md` (the page is actually about occupational health)
- everything else → preserve slug

The complete map lives in `content-cache/url-map.json`.
